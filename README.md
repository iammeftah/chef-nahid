# 🍽️ Restaurant Digital Menu

A simple digital menu web app for the restaurant, built with [Next.js](https://nextjs.org) and deployed for free on [Vercel](https://vercel.com).

Customers scan the QR code on the table / receipt / signage and land directly on the live menu page.

## 🛠️ Tech Stack

- [Next.js](https://nextjs.org) — React framework
- [Vercel](https://vercel.com) — Hosting & deployment (free `.vercel.app` domain)
- QR Code generated for the deployed URL

## 🚀 Getting Started (local development)

```bash
# Install dependencies
npm install

# Run the dev server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the app.

## 📦 Deployment

The app is deployed automatically to Vercel on every push to `main`.
